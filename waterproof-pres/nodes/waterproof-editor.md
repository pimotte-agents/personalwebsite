# Waterproof editor

[Releases](https://www.npmjs.com/package/@impermeable/waterproof-editor) · [Sources](https://github.com/impermeable/waterproof-editor)

- Reusable, configurable editor
- Displays exercise sheets: text in Markdown or LaTeX, mixed with code
- Supports:
  - Input areas that limit where students can type
  - LaTeX
  - Hints: collapsible regions
- Also runs in the browser, in the [demo](#demo)
