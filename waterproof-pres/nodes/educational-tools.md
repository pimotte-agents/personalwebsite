# Educational tools

- [Mizar](#mizar): proof checker with a language close to the mathematical vernacular
- [Isar](#isar): Isabelle's language for readable, structured proofs
- [ProofWeb](#proofweb): teaching logic with Coq through a web interface
- [Naproche](#naproche): checks mathematical texts in a controlled natural language
- [Lurch](#lurch): a word processor that checks the reasoning in a document
- [Edukera](#edukera): web platform for proof exercises, built on Coq
- [Diproche](#diproche): checks proof exercises in a controlled fragment of German
- [D∃∀duction](#deaduction): graphical interface to Lean
- [Verbose Lean](#verbose-lean): controlled natural language for Lean
- [ProofBuddy](#proofbuddy): Isabelle in the browser, recording how students work
- [Yalep](#yalep): a small proof language on Lean for high school
