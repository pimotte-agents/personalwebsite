# Educational* tools

- [Mizar](#mizar) (1973): proof checker with a language close to mathematical vernacular
- [Isar](#isar) (1999): Isabelle's language for readable, structured proofs
- [ProofWeb](#proofweb) (2007): teaching logic with Coq in the browser
- [Naproche](#naproche) (2009): checks proofs written in controlled natural language
- [Lurch](#lurch) (2013): a word processor that checks the reasoning in a document
- [Edukera](#edukera) (2016): point-and-click proofs on the web, built on Coq
- [Diproche](#diproche) (2020): checks beginners' proofs in controlled German
- [D∃∀duction](#deaduction) (2020): graphical proofs on top of Lean
- [Verbose Lean](#verbose-lean) (2021): controlled natural language for Lean
- [ProofBuddy](#proofbuddy) (2023): Isabelle in the browser, recording how students work
- [Yalep](#yalep) (2025): a small proof language on Lean for high school
