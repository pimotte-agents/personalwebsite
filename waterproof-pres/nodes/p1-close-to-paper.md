# P1: Close to paper

*Exercises and accepted proofs read like their paper versions.*

- Every difference with paper may become part of how students write proofs.
- Use the statement and notation of the course material.
- With $\exists \delta > 0$, choosing a value creates a separate step for the condition:

  ```
  Choose c := b - a + 1.
  { Indeed, c ∈ ℝ. }
  ```
- Hide formal details: coercions, type ascriptions, `Real.sqrt`.
