# Coding scheme

Transcribed by two teaching assistants, coded line by line by Otte, as in [Wemmenhove et al.](#research-proof-structure); `continued` and `no code` even out differences between transcribers

| Code | Example |
|:--|:--|
| intro and elim of ∀, ∃, ⇒, ∨; ¬-intro | "Let $x\in\mathbb{R}$ be arbitrary", "Choose $y := 14$" |
| domain-check | "$14\in\mathbb{R}$" |
| signpost-goal | "It suffices to show $\exists y\in\mathbb{R},\,q(y)$" |
| signpost-case | "Case 1: $\neg p(x)$" |
| signpost-concl | "In both cases $\neg p(x)\vee\exists y\in\mathbb{R},\,q(y)$" |
| unfold, use-thm | "We know that $p(x)\vee\neg p(x)$" |
| continued, scrap, no code | continued steps, draft work, invalid steps |
