# Statistical model

- Dependent variable: grade in the first quiz
- Main variable: number of exercises completed in Waterproof (self-reported in the exit survey; nearly all use was in the first three weeks)
- Fixed effects for prior knowledge and skills: the pretest grade and the secondary school mathematics grade
- Random effects: teacher and study programme
- All numerical variables standardised; students whose use of Waterproof is unknown are excluded
- Sensitivity check: study programme as a fixed effect ([results](#mixed-model))
