# P2: Acceptance matches the teacher's judgement

*Accept all solutions a teacher would allow, and none that a teacher would not allow.*

- Flexibility vs. strictness: easy to get one, hard to get both.
- What is allowed depends on the learning goal and the point in the course: configure the automation per exercise.
- Step size: no larger than the steps in nearby worked examples.
- In practice: strictness failures are rare, flexibility failures happen all the time.
