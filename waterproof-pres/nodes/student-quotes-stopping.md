# Why students stopped, in their words

- “I usually spent more time on wondering how Waterproof wanted me to write things, than on actually doing maths.”
- “I knew that what I wanted to do was correct, but I just didn't know how to make sure that Waterproof knew what I was doing as well.”
- “I got really frustrated when Waterproof did not approve of my exercise because a "-" wasn't placed correctly”
- “Waterproof made me just guess what to do (because it'd check it instantly) instead of actually thinking about it”
- “At some point, writing proofs is not writing proofs anymore, but only guessing how Waterproof wants you to write your prove, even if your proof is completely correct.”
- “I stopped using it because it took me too long to finish each exercise because the program would load for so long.”
