# Naive type theory

$$
\begin{aligned}
\text{Type } X &\text{ --- } \text{Set } X \\
\text{Term } x : X &\text{ --- } \text{Element } x \in X \\
\text{Function } X \to Y &\text{ --- } \text{Function } X \to Y \\
\text{Product } X \times Y &\text{ --- } \text{Product } X \times Y \\
\text{Sum } X \oplus Y &\text{ --- } \text{Disjoint union } X \sqcup Y
\end{aligned}
$$
