# Curry–Howard correspondence

$$
\begin{aligned}
\text{Type } P &\text{ --- } \text{Proposition } P \\
\text{Term } p : P &\text{ --- } \text{Proof } p \text{ of } P \\
\text{Function } P \to Q &\text{ --- } \text{Implication } P \Rightarrow Q \\
\text{Product } P \times Q &\text{ --- } \text{Conjunction } P \land Q \\
\text{Sum } P \oplus Q &\text{ --- } \text{Disjunction } P \lor Q
\end{aligned}
$$
